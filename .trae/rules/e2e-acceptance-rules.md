# E2E 项目验收规则（强制版）

> **生效日期**: 2026-04-05  
> **制定原因**: HoloPix E2E 测试生产事故  
> **适用范围**: 所有 E2E 自动化测试项目

---

## 第一章：测试设计红线（必须遵守）

### 1.1 验收测试定义（必须）

**必须**: 验收测试必须验证**业务功能**是否正常工作，而非仅验证 UI 元素存在性。  
**必须**: 每个测试用例必须包含**数据验证**步骤。  
**必须**: 每个测试用例必须验证**API 调用**是否成功。  
**不准**: 不准仅验证按钮可点击、表单可填写等表层操作。

### 1.2 测试用例设计标准（必须）

**必须**: 测试用例必须基于 PRD 文档中的**用户故事**设计。  
**必须**: 测试用例必须覆盖**端到端业务流程**，而非单点操作。  
**必须**: 测试用例必须包含**前置条件**、**操作步骤**、**预期结果**三部分。  
**不准**: 不准设计仅验证页面加载、元素存在的用例。  
**不准**: 不准缺少数据断言的测试用例通过验收。

---

## 第二章：功能实现验收（必须遵守）

### 2.1 前端功能实现（必须）

**必须**: 前端代码必须实现真实的**API 调用**，不准仅显示提示消息。  
**必须**: 前端代码必须实现**数据加载和渲染**，不准仅显示"加载中..."占位符。  
**必须**: 前端代码必须实现**业务逻辑处理**，不准仅搭建 UI 骨架。  
**必须**: 所有按钮点击必须触发**实际功能**，不准仅调用 `showNotification()`。

**不准**: 不准有以下空实现模式：
```javascript
// 不准示例 - 空实现
function loadData() {
    container.innerHTML = '<p>加载中...</p>'; // 不准：无实际数据加载
}

function submitForm() {
    showNotification('提交成功'); // 不准：无 API 调用
}
```

### 2.2 后端 API 实现（必须）

**必须**: 后端必须提供可正常工作的 API 接口。  
**必须**: API 必须返回真实数据，不准返回硬编码假数据。  
**必须**: API 必须实现数据持久化，不准仅内存存储。

## 第三章：测试验证标准（必须遵守）

### 3.1 数据验证（必须）

**必须**: 测试必须验证**数据是否正确加载**到页面。  
**必须**: 测试必须验证**数据内容**是否符合预期（如模型 ID、名称、状态等）。  
**必须**: 测试必须验证**数据操作**（增删改查）是否生效。

**不准**: 不准仅验证容器元素存在，不验证内部数据：
```typescript
// 不准示例
await expect(page.locator('.model-list')).toBeVisible(); // 不准：未验证数据

// 必须示例
await expect(page.locator('.model-item').first()).toContainText('模型名称'); // 必须：验证数据
```

### 3.2 API 验证（必须）

**必须**: 测试必须验证 API 请求是否**实际发出**。  
**必须**: 测试必须验证 API 响应状态码是否为 200。  
**必须**: 测试必须验证 API 响应数据是否正确。

**不准**: 不准仅等待固定时间，不验证 API 完成：
```typescript
// 不准示例
await page.click('#sync-btn');
await page.waitForTimeout(3000); // 不准：未验证 API 完成

// 必须示例
await page.click('#sync-btn');
await page.waitForResponse('**/api/models/sync'); // 必须：验证 API
await expect(page.locator('.model-item')).toHaveCountGreaterThan(0); // 必须：验证数据
```

### 3.3 业务流程验证（必须）

**必须**: 测试必须验证**完整业务流程**，从输入到输出。  
**必须**: 测试必须验证**状态变化**（如任务状态：提交→处理中→完成）。  
**必须**: 测试必须验证**副作用**（如生成图片后素材库增加）。

## 第四章：截图和视频规范（必须遵守）

### 4.1 截图内容（必须）

**必须**: 截图必须包含**数据内容**，而非仅空白页面。  
**必须**: 截图命名必须使用**中文步骤名称**，描述具体操作。  
**必须**: 关键步骤必须截图：操作前、操作后、数据验证。

**不准**: 不准截图仅显示"加载中..."、"暂无数据"等空状态。

### 4.2 视频录制（必须）

**必须**: 每个测试必须录制**完整操作视频**。  
**必须**: 视频必须能清晰展示**功能执行过程**。

## 第六章：禁止事项（不准）

### 6.1 测试设计禁止（不准）

**不准**: 不准设计无数据断言的测试用例。

**不准**: 不准使用 `showNotification()` 替代实际功能实现。  
**不准**: 不准使用占位符 HTML 替代真实数据渲染。  
**不准**: 不准使用硬编码假数据替代 API 响应。

### 6.3 验收报告禁止（不准）

**不准**: 不准仅凭测试通过数量判定系统可用。  
**不准**: 不准提交无业务功能验证的测试报告。  
**不准**: 不准隐瞒功能未实现的事实。

## 第七章：事故案例（必须学习）

### 7.1 HoloPix E2E 测试事故（2026-04-05）

**事故描述**:  
交付的 56 个 E2E 测试用例全部通过，但系统功能完全不可用。

**根本原因**:  
1. 测试仅验证 UI 元素存在性，未验证业务功能
2. 前端代码全是空实现，仅显示提示消息
3. 没有验证 API 调用和数据加载

**违反规则**:  
- 违反 1.1：未验证业务功能
- 违反 2.1：前端空实现
- 违反 3.1：未验证数据
- 违反 3.2：未验证 API
- 违反 6.1：测试设计错误
- 违反 6.2：功能实现违规

**后果**:  
- 测试价值为零
- 生产风险极高
- 资源严重浪费
- 团队信任受损

## 附录：正确 vs 错误示例

### 示例 1：模型列表加载测试

**错误（不准）**:
```typescript
test('TC-201 同步模型列表', async ({ page }) => {
  await page.click('#sync-btn'); // 不准：仅点击按钮
  await page.waitForTimeout(3000);
  await expect(page.locator('.model-list')).toBeVisible(); // 不准：未验证数据
});
```

**正确（必须）**:
```typescript
test('TC-201 同步模型列表', async ({ page }) => {
  // 必须：验证 API 调用
  const [response] = await Promise.all([
    page.waitForResponse('**/api/models/sync'),
    page.click('#sync-btn')
  ]);
  expect(response.status()).toBe(200);
  
  // 必须：验证数据渲染
  await expect(page.locator('.model-item')).toHaveCountGreaterThan(0);
  await expect(page.locator('.model-item').first()).toContainText('模型ID');
});
```

### 示例 2：生成图片测试

**错误（不准）**:
```typescript
test('TC-010 生成图片', async ({ page }) => {
  await page.fill('#prompt', '测试');
  await page.click('#generate-btn'); // 不准：仅点击按钮
  await expect(page.locator('.notification')).toContainText('已提交'); // 不准：仅验证提示
});
```

**正确（必须）**:
```typescript
test('TC-010 生成图片', async ({ page }) => {
  await page.fill('#prompt', '测试');
  
  // 必须：验证 API 调用
  const [response] = await Promise.all([
    page.waitForResponse('**/api/generate'),
    page.click('#generate-btn')
  ]);
  expect(response.status()).toBe(200);
  
  // 必须：验证任务创建
  const taskId = await response.json().then(r => r.task_id);
  await expect(page.locator('.task-item')).toContainText(taskId);
  
  // 必须：验证状态轮询
  await page.waitForSelector('.task-status:has-text("完成")', { timeout: 60000 });
  
  // 必须：验证结果展示
  await expect(page.locator('.result-image')).toBeVisible();
});
```
