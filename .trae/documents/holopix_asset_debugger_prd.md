# HoloPix 素材调试器 PRD 文档

## 1. 产品概述

**HoloPix 素材调试器**是一个用于测试和调试 HoloPix API 文生图功能的综合性工具，支持多模型组合、姿势参考、参数调优和素材管理，为用户提供一站式的素材生成和管理体验。

### 1.1 核心价值
- **多模型叠加**：支持最多5个模型的组合使用，实现风格融合
- **姿势参考**：内置火柴人编辑器和预设姿势，提供角色姿态参考
- **参数调优**：丰富的参数配置和实时预览，帮助用户找到最佳生成参数
- **素材管理**：完整的任务追踪和素材库管理，便于回溯和复用
- **快捷配置**：支持保存和加载配置预设，提高工作效率

### 1.2 目标用户
- 游戏美术设计师
- 内容创作者
- API 调试工程师
- 模型训练师

## 3. 核心功能描述

### 3.1 文生图生成模块

#### 3.1.1 模型配置
- **功能**：选择和配置多个模型，支持模型叠加
- **参数**：
  - 模型ID：支持自定义模型选择
  - 模型强度：0-1范围的滑块调节
  - 模型数量：最多5个
- **预设组合**：
  - Q版卡通人物：23v56pjLui, 2BB56NBV2F, iKXx6k89s3
  - 中国风场景：c3P5zkc92s, L3W5F7EE2P, 2KJ5GG8CC3
- **操作流程**：
  1. 点击"添加模型"按钮打开模型选择器
  2. 从模型列表中选择模型（支持搜索和筛选）
  3. 调节模型强度滑块
  4. 点击"删除"按钮移除模型
  5. 点击预设组合按钮快速应用模型组合

#### 3.1.2 文本提示词
- **功能**：输入正向和反向提示词
- **参数**：
  - 正向提示词：描述想要生成的内容，最多2000字符
  - 反向提示词：描述不想要的内容（部分模型不支持）
- **操作**：在文本框中输入提示词，支持多行输入

#### 3.1.3 画面控制
- **功能**：控制生成图片的基本参数
- **参数**：
  - 画面比例：1:1, 16:9, 9:16, 4:3, 3:4, 3:2, 2:3, 21:9
  - 随机种子：-1为随机，固定值可复现结果
  - 画面指导权重：3-6（越大越整洁，部分模型必填）
  - 出图数量：1-4张（根据模型不同有上限）

#### 3.1.4 增强选项
- **功能**：提供额外的生成增强选项
- **参数**：
  - 脸部修复：额外细化脸部生成
  - 高清修复：A1/SDXL等模型支持，可选择放大倍数（1.5x或2x）
  - 简单背景：生成简洁背景（部分模型不支持）
  - 画面增强：A1/Pony/Animagine支持，强度0-5

#### 3.1.5 参考图片
- **功能**：提供形象样式和姿态参考
- **参数**：
  - 形象样式参考：图片URL或Base64
  - 参考模式：standard（标准参考）或color（氛围颜色）
  - 参考权重：0-1
  - 角色姿态参考：DwPose格式图片URL（火柴人姿势）
- **操作**：
  - 输入形象样式参考URL
  - 点击"选择火柴人姿势"打开姿势选择器
  - 选择预设姿势或自定义姿势
  - 点击"清除"按钮移除姿势

#### 3.1.6 任务提交和轮询
- **功能**：提交生成任务并实时追踪状态
- **流程**：
  1. 点击"生成图片"按钮
  2. 显示进度条和状态信息
  3. 每5秒自动轮询任务状态
  4. 任务完成后显示生成结果
  5. 支持下载和保存到素材库

#### 3.1.7 快捷配置
- **功能**：保存和加载配置预设
- **操作**：
  - 点击"保存配置"将当前参数保存为预设
  - 点击"加载配置"打开预设选择器
  - 点击预设卡片快速应用配置

### 3.2 模型管理模块

#### 3.2.1 模型列表
- **功能**：展示和管理可用模型
- **操作**：
  - 点击"同步模型列表"从API获取最新模型
  - 查看模型基本信息（ID、名称、类型、风格）
  - 点击模型行展开详情
  - 支持固定/取消固定模型
  - 支持显示/隐藏模型

#### 3.2.2 模型筛选
- **功能**：多维度筛选模型
- **筛选条件**：
  - 显示状态：全部、显示中、已隐藏
  - 模型类型
  - 风格类型
  - 基础模型
  - 模型标签
  - 模型名称模糊搜索
  - 模型ID精确筛选（支持多个ID）

### 3.3 任务管理模块

#### 3.3.1 任务列表
- **功能**：展示生成任务历史
- **信息**：
  - 任务状态（已提交、处理中、成功、失败）
  - 提示词摘要
  - 生成时间
  - 耗时
- **操作**：
  - 点击"刷新列表"获取最新任务
  - 点击任务查看详情

#### 3.3.2 任务详情
- **功能**：查看任务完整信息和生成结果
- **信息**：
  - 完整参数详情
  - 生成的图片预览
  - 状态和时间信息
  - 参数差异（如果有）
- **操作**：
  - 点击图片查看大图
  - 复制任务参数
  - 下载图片

### 3.4 素材管理模块

#### 3.4.1 素材列表
- **功能**：展示已保存的素材
- **信息**：
  - 素材预览图
  - 保存时间
  - 来源任务
- **操作**：
  - 点击"刷新素材"获取最新素材
  - 点击素材卡片查看详情
  - 下载素材
  - 删除素材

### 3.5 火柴人调试模块

#### 3.5.1 火柴人编辑器
- **功能**：创建和编辑火柴人姿势
- **工具**：
  - 预设动作：站立、挥动武器、躲避、防御
  - 画布编辑：支持点击拖拽编辑骨骼
  - 导出功能：导出PNG图片
  - 描述生成：自动生成姿势描述

#### 3.5.2 姿势管理
- **功能**：管理预设和自定义姿势
- **操作**：
  - 筛选姿势：全部、预设、自定义
  - 保存自定义姿势
  - 点击姿势应用到编辑器
  - 点击姿势用于文生图
  - 初始化预设姿势

## 4. 技术架构

### 4.1 前端架构
- **技术栈**：HTML5, CSS3, JavaScript (ES6+)
- **布局**：响应式网格布局，支持多屏幕尺寸
- **交互**：原生JavaScript事件处理，无第三方框架依赖
- **通信**：Fetch API 与后端通信
- **状态管理**：全局变量和闭包管理应用状态

### 4.2 后端架构
- **技术栈**：Python, Flask
- **API**：RESTful API 接口
- **数据库**：SQLite 本地数据库
- **核心服务**：
  - 模型管理服务
  - 任务管理服务
  - 素材管理服务
  - 火柴人姿势服务
  - HoloPix API 客户端

### 4.3 数据流
1. **用户操作** → 前端界面交互
2. **参数收集** → 构建请求参数
3. **API调用** → 发送请求到后端
4. **任务提交** → 后端转发到 HoloPix API
5. **状态轮询** → 前端定期查询任务状态
6. **结果处理** → 显示生成结果
7. **数据持久化** → 保存到本地数据库
