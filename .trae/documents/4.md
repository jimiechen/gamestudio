生图任务查询进度协议
创建任务
网络协议	请求地址	请求方法	请求格式	响应格式
https	/v1/images/generations/queryProgress	POST	application/json	application/json
请求头
字段	值	描述
Content-Type	application/json	application/json
Authorization	鉴权信息，参考接口鉴权	鉴权信息，参考接口鉴权
查询任务
查询任务
字段	类型	必填	默认值	描述
clientIds	list	是	无	生图任务提交成功响应信息体里面任务ID列表，最多1次查询10个生图任务。
请求示例
JSON
JSON
{
    "data":{
        "clientIds":[
            "10017-176371296695583034-"]
    }
}
响应参数
字段	参数说明	类型	描述
code	错误代码	int	
msg	错误信息	string	
clientList	任务状态列表	list	list内部存放1~10个client_task对象
client_task
字段	参数说明	类型	描述
clientId	任务ID	string	
status	生图状态	string	//任务状态，枚举值：submitted（已提交）、processing（处理中）、succeed（成功）、failed（失败）
imgUrls	图片下载地址	list	如果status=succeed时，返回url地址，地址有效期7天
content	图片推词文案	string	使用图片推词才会有数据，否则为空
statusMsg	状态状态描述	string	//任务状态信息，当任务失败时展示失败原因（如触发平台的内容风控等）
createdTime	任务创建时间	long	任务创建时间，Unix时间戳、单位ms
