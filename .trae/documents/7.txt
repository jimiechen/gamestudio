模型参数查询	
查询对应模型的具体参数
注：该接口免费调用，方便您查询对应模型的具体参数，但请您注意控制请求速率（QPS<=1）

网络协议	请求地址	请求方法	请求格式	响应格式
https	/v1/model/apiDetail	POST	 application/json	application/json
请求头
字段	值	描述
id	string	模型唯一代码
Content-Type	application/json	数据交换格式
Authorization	鉴权信息，参考接口鉴权	鉴权信息，参考接口鉴权
请求示例
JSON
JSON
{
    "data": {
       "id":"15D34DF2CZ"
    }
}
响应参数
字段	类型	描述
modelAvailable	bool	是否可用，如果用户无该模型可用权限，则下面信息不展示
modelName	string	模型名字
id	string	模型唯一代码
modelTags	string	模型标签
introduction	string	模型简介
modelType	string	模型类型
styleType	string	风格类型
baseModel	string	基础模型
coverImage	string	封面图URL
modelDetailsImages	string	详情图URL
commercialLicense	string	商用许可
