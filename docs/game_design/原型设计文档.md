# 《三国英杰传：乱世求生》原型设计文档

## 一、原型概述

### 1.1 原型目标
验证核心玩法的乐趣和可行性，包括：
- 幸存者玩法的爽快感
- 三国题材的代入感
- 武器/技能组合的策略性
- 移动端的操作体验

### 1.2 原型范围
**MVP（最小可行产品）功能：**
- 1个可玩武将（关羽）
- 1个关卡（荒野战场）
- 3种武器类型
- 5种敌人类型
- 基础升级系统
- 1个BOSS战

### 1.3 开发周期
**2周原型开发**

- **伤害**：25
- **攻击间隔**：0.8秒
- **特性**：击退效果

#### 弓箭（远程）
- **攻击范围**：直线
- **攻击距离**：300像素
- **伤害**：15
- **攻击间隔**：0.5秒
- **特性**：穿透1个敌人

#### 火球术（法术）
- **攻击范围**：圆形AOE
- **攻击距离**：200像素
- **伤害**：20
- **攻击间隔**：1.2秒
- **特性**：持续燃烧3秒（每秒5伤害）

### 2.4 升级系统（原型版）

#### 经验值需求
| 等级 | 所需经验 | 属性提升 |
|------|----------|----------|
| 1→2 | 100 | 生命+10 |
| 2→3 | 150 | 攻击+10% |
| 3→4 | 200 | 移速+10% |
| 4→5 | 250 | 新武器/升级 |
| 5→6 | 300 | 生命+10 |
| 6→7 | 350 | 攻击+10% |
| 7→8 | 400 | 移速+10% |
| 8→9 | 450 | 新武器/升级 |
| 9→10 | 500 | 全属性+15% |

#### 升级选项（随机3选1）
1. **新武器**：获得弓箭或火球术
2. **升级武器**：现有武器等级+1（伤害+20%，范围+10%）
3. **属性提升**：生命+20 / 攻击+15% / 移速+10%

### 2.5 关卡流程（原型版）

#### 时间线
```
0:00  - 游戏开始，少量黄巾贼
1:00  - 敌人数量增加
2:00  - 出现黄巾力士
3:00  - 出现黄巾法师
4:00  - 敌人波次增强
5:00  - 出现骑兵
6:00  - 混合所有敌人类型
7:00  - 精英敌人增多
8:00  - 最终波次
9:00  - BOSS张角出现
10:00 - 击杀BOSS或死亡结束
```

#### 地图规格
- **尺寸**：2000x2000像素
- **边界**：不可穿越的地图边缘
- **障碍物**：随机分布的石头、树木（可绕不可穿）
- **出生点**：地图中心

## 四、技术规格

### 4.1 开发工具
- **引擎**：Godot 4.x（开源、轻量、适合原型）
- **语言**：GDScript
- **版本控制**：Git

### 4.2 项目结构
```
/project
├── /assets
│   ├── /sprites        # 角色、敌人精灵图
│   ├── /tilesets       # 地图图块
│   ├── /ui            # UI元素
│   └── /audio         # 音效（可选）
├── /scenes
│   ├── /player        # 玩家相关场景
│   ├── /enemies       # 敌人场景
│   ├── /weapons       # 武器场景
│   ├── /ui            # UI场景
│   └── /levels        # 关卡场景
├── /scripts
│   ├── /components    # 可复用组件
│   ├── /managers      # 游戏管理器
│   └── /utils         # 工具函数
└── project.godot
```

### 4.3 核心组件

#### 玩家控制器 (PlayerController)
```gdscript
# 伪代码
class PlayerController:
    - health: float
    - move_speed: float
    - weapons: Array[Weapon]
    - experience: int
    - level: int
    
    + _physics_process(delta): void
    + take_damage(amount): void
    + gain_experience(amount): void
    + level_up(): void
```

#### 敌人AI (EnemyAI)
```gdscript

    - attack_cooldown: float

    + chase_player(): void

```

#### 武器系统 (Weapon)
```gdscript

    - damage: float
    - attack_range: float
    - attack_speed: float
    - level: int
    
    + attack(): void
    + upgrade(): void
```

#### 生成器 (Spawner)
```gdscript
# 伪代码
class Spawner:
    - spawn_points: Array[Vector2]

    - spawn_rate: float

    + spawn_enemy(): void

```

### 4.4 性能目标
- **同屏敌人**：50+
