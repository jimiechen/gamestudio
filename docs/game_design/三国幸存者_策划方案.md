# 《三国英杰传：乱世求生》游戏策划方案

## 一、游戏核心概念

### 1.1 游戏定位
- **游戏类型**：2D俯视视角Roguelike幸存者游戏
- **平台**：PC / 移动端 / Switch
- **目标用户**：喜欢三国题材、动作游戏、Roguelike元素的玩家
- **游戏时长**：单局15-30分钟

### 1.2 核心主题
**"乱世之中，一人成军"**

玩家扮演三国时期的名将或自创武将，在敌军包围中杀出重围。融合经典幸存者玩法与三国特色：
- **割草爽感**：一骑当千的战场体验
- **策略搭配**：武器、技能、羁绊组合
- **历史沉浸**：经典战役、名将、兵器还原

### 1.3 美术风格
- **风格**：Q版卡通 + 水墨国风
- **视角**：2D俯视45°角
- **色调**：暖色调为主，战场氛围浓烈
- **参考**：《吸血鬼幸存者》+ 《三国杀》Q版风格

## 二、核心玩法机制

### 2.1 基础操作
| 操作 | 功能 |
|------|------|
| 虚拟摇杆/WASD | 移动 |
| 自动攻击 | 进入射程自动攻击最近的敌人 |
| 技能按钮 | 释放主动技能（有CD） |
| 闪避/冲刺 | 短暂无敌位移 |

### 2.2 核心循环
```
开始游戏 → 选择武将 → 战场生存 → 击杀敌人 → 获得经验 → 升级选择 → 
获得装备/技能 → 挑战BOSS → 通关/死亡 → 解锁新内容 → 再次挑战
```

### 2.3 战斗系统

#### 2.3.1 经验与升级
- 击杀敌人掉落经验球
- 升级时三选一：
  - **新武器/技能**
  - **强化已有武器**
  - **属性提升**（攻击/生命/移速/暴击等）

#### 2.3.2 武器系统
| 武器类型 | 特点 | 代表武器 |
|----------|------|----------|
| 近战 | 高伤害、贴身战斗 | 青龙偃月刀、丈八蛇矛 |
| 远程 | 安全输出、持续伤害 | 诸葛连弩、弓箭 |
| 法术 | AOE伤害、控场 | 太平要术、八卦阵 |
| 召唤 | 召唤单位协助战斗 | 虎符、兵书 |

#### 2.3.3 技能系统
- **被动技能**：自动生效（如：吸血、暴击、范围增加）
- **主动技能**：手动释放（如：无双乱舞、火攻、治疗）
- **终极技能**：怒气积攒释放，清屏效果

### 2.4 特色机制：羁绊系统
当同时装备特定组合时激活强力效果：

| 羁绊名称 | 组合要求 | 效果 |
|----------|----------|------|
| 桃园结义 | 关羽+张飞+刘备武器 | 生命值+50%，复活一次 |
| 五虎上将 | 任意五虎将武器 | 攻击力+100% |
| 卧龙凤雏 | 诸葛亮+庞统技能 | 技能CD-50% |
| 火烧赤壁 | 火攻+东风 | 火焰伤害+200% |
| 吕布无双 | 方天画戟+赤兔马 | 攻击速度+150% |

## 三、角色与武将系统

### 3.1 初始武将（免费解锁）

#### 刘备
- **定位**：平衡型
- **初始武器**：双股剑
- **特色**：仁德之心（击杀敌人概率回血）
- **终极技能**：桃园结义（召唤关羽张飞协助10秒）

#### 关羽
- **定位**：近战爆发
- **初始武器**：青龙偃月刀
- **特色**：武圣（生命值越低伤害越高）
- **终极技能**：水淹七军（大范围斩击）

#### 张飞
- **定位**：坦克控制
- **初始武器**：丈八蛇矛
- **特色**：咆哮（周期性恐惧周围敌人）
- **终极技能**：当阳怒吼（全屏眩晕3秒）

### 3.2 解锁武将

| 武将 | 解锁条件 | 定位 | 特色 |
|------|----------|------|------|
| 诸葛亮 | 通关第1章 | 法术输出 | 八卦阵自动防御 |
| 赵云 | 累计击杀10000敌人 | 机动刺客 | 七进七出（闪避后增伤） |
| 吕布 | 单局击杀500敌人 | 狂战士 | 无双模式（越战越强） |
| 貂蝉 | 使用女性武将通关 | 控制辅助 | 离间（敌人互相攻击） |
| 曹操 | 收集所有魏国武器 | 统帅型 | 号令（召唤士兵） |
| 周瑜 | 使用火攻通关 | 范围法师 | 火神（火焰伤害翻倍） |
| 孙尚香 | 使用弓箭通关 | 远程射手 | 枭姬（暴击率极高） |
| 华佗 | 累计回血10000 | 治疗辅助 | 神医（持续回血光环） |

### 3.3 武将成长
- **等级**：每局独立，最高20级
- **星级**：永久提升，通过碎片升级
- **天赋树**：解锁被动技能槽位、属性加成

## 四、关卡设计

### 4.1 章节结构

#### 第一章：黄巾之乱
- **场景**：荒野战场
- **敌人**：黄巾贼、黄巾力士、黄巾法师
- **BOSS**：张角（召唤雷电、分身术）
- **时长**：15分钟
- **特色**：教学关，熟悉基础操作

#### 第二章：虎牢关之战
- **场景**：雄关要塞
- **敌人**：董卓军、西凉铁骑、弓箭手
- **BOSS**：吕布（三阶段：骑马→步战→狂暴）
- **时长**：20分钟
- **特色**：狭窄地形，考验走位

#### 第三章：赤壁之战
- **场景**：长江战船
- **敌人**：曹军水兵、连环船、火攻部队
- **BOSS**：曹操（召唤援军、火攻技能）
- **时长**：25分钟
- **特色**：动态火焰伤害区域

#### 第四章：夷陵之战
- **场景**：山林密林
- **敌人**：蜀军、藤甲兵、火攻队
- **BOSS**：陆逊（火攻专家、地形改变）
- **时长**：25分钟
- **特色**：树林可燃烧改变地形

#### 第五章：五丈原
- **场景**：星落战场
- **敌人**：魏军精锐、机关兽、谋士
- **BOSS**：司马懿（复制玩家技能、时间操控）
- **时长**：30分钟
- **特色**：最终挑战，全机制综合

### 4.2 特殊关卡

#### 无尽模式
- 无限波次敌人
- 每5波一个BOSS
- 全球排行榜

#### 挑战模式
- 特定条件通关（如：只用近战武器、不受伤等）
- 解锁特殊奖励

#### 历史战役
- 还原经典战役（官渡、长坂坡等）
- 固定武将和装备
- 达成历史目标

## 五、敌人设计

### 5.1 普通敌人

| 敌人类型 | 特点 | 应对策略 |
|----------|------|----------|
| 步兵 | 数量多、血量低 | AOE清理 |
| 骑兵 | 速度快、冲锋攻击 | 走位躲避 |
| 弓箭手 | 远程攻击 | 优先击杀 |
| 法师 | 范围技能 | 快速近身 |
| 盾兵 | 高防御、正面减伤 | 绕后攻击 |
| 刺客 | 隐身、背刺 | 保持移动 |

### 5.2 精英敌人
- 带特殊词缀（如：火焰、冰冻、毒液）
- 掉落高级装备

### 5.3 BOSS设计

#### 张角（第一章BOSS）
- **血量**：10000
- **技能1**：太平要术（召唤3道雷电）
- **技能2**：黄天当立（召唤黄巾力士）
- **技能3**：分身术（制造2个分身）
- **弱点**：分身血量低，优先清理

#### 吕布（第二章BOSS）
- **血量**：20000
- **阶段1（骑马）**：冲锋攻击，范围大
- **阶段2（步战）**：方天画戟连击
- **阶段3（狂暴）**：攻击速度翻倍
- **弱点**：阶段转换时硬直长

## 七、成长与解锁系统

### 7.1 局外成长（永久）
- **武将等级**：提升基础属性
- **天赋树**：解锁新能力
- **装备图鉴**：收集解锁加成
- **成就系统**：完成获得奖励

### 7.2 货币系统
- **铜钱**：基础货币，用于升级
- **元宝**：高级货币，解锁武将
- **将魂**：武将碎片，升星用

### 7.3 解锁内容
- 新武将
- 新武器
- 新技能
- 新关卡
- 皮肤外观

## 九、技术需求

### 9.1 开发引擎
- **推荐**：Unity 2D 或 Godot
- **语言**：C# / GDScript

### 9.2 性能目标
- 同屏敌人：100+
- 帧率：60FPS
- 加载时间：<3秒

### 9.3 所需资源
- 角色动画：8方向行走+攻击
- 敌人：20+种
- 特效：技能、受击、死亡
- UI：国风界面设计
- 音效：武器、技能、BGM
