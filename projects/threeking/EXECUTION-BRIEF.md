- 下午: 实现地图边界 + 相机跟随

**验收标准**:
- [ ] 玩家可以用WASD移动

- [ ] 运行稳定60FPS

**Day 3**:
- 上午: 创建敌人场景、实现追踪AI
- 下午: 实现敌人生成系统

**Day 4**:
- 上午: 实现击杀系统 (碰撞检测 + 分数)
- 下午: 实现玩家受伤与死亡

**Day 5**:
- 上午: 实现UI系统 (血条、分数、时间)
- 下午: 实现游戏循环 (开始、结束、重启)

**验收标准**:
- [ ] 敌人从屏幕边缘生成并追踪玩家
- [ ] 子弹命中敌人造成伤害
- [ ] 敌人HP<=0时死亡，玩家+10分
- [ ] 敌人触碰玩家，玩家-10HP
- [ ] 玩家受伤后有1秒无敌闪烁
- [ ] 玩家HP<=0时游戏结束
- [ ] 按R键可以重新开始
