## 《五虎将》武将设计文档评审报告

### 一、总体评价

**优点**：
- 结构完整，从属性、技能、羁绊、美术到验收标准覆盖全面
- 技能设计差异化明显，符合角色定位（关羽爆发、张飞坦克、赵云机动、马超极限输出、黄忠远程）
- 羁绊系统层次丰富（2人/3人/5人），鼓励多种阵容搭配
- 数值成长公式清晰，平衡性测试场景具体
- 与之前的 Godot 4 + Holopix 开发方案衔接良好，美术提示词可直接用于素材生成

**主要风险**：
- 部分技能数值过高，可能破坏平衡
- 技能机制复杂度较高，实现成本和性能需评估
- 与 Roguelike 核心循环（随机 Build、永久死亡）的融合点未明确

---

### 二、逐项评审

#### 1. 基础属性与定位

| 武将 | 评审意见 |
|------|----------|
| 关羽 | 攻击5星、防御3星，定位爆发输出，合理。但生命4星（120）与张飞5星（150）差距不大，建议关羽HP下调至105-110，强化“攻强防弱”特色 |
| 张飞 | 防御5星、生命5星，坦克定位明确。但攻击4星（20）低于关羽（25），差值略小，建议张飞基础攻击降至18，进一步突出肉盾特性 |
| 赵云 | 机动5星、攻击速度5星，符合预期。但基础攻击22、防御6，过于均衡，建议攻击降至20，增加暴击率基础值（如10%），强化“敏捷暴击”特色 |
| 马超 | 攻击5星、防御2星，极限输出定位正确。但生命90、防御5，生存能力可能过低，在 Roguelike 高难度下容错率差，建议被动增加少量减伤或击杀回血机制 |
| 黄忠 | 攻击5星、攻速2星，远程狙击合理。但基础攻击30最高，配合被动“对精英/BOSS +30%”可能导致单体爆发过强，建议基础攻击降至27，平衡输出峰值 |

**成长公式**：线性成长（每级8%~10%）在 Roguelike 中可能导致后期属性膨胀，建议改为递减成长（前10级快速成长，后10级缓慢）或引入“局内成长”代替部分等级成长。

#### 2. 技能设计

##### 关羽 - 水淹七军
- **机制**：范围伤害 + 减速 + 对精英额外伤害 → 合理
- **数值**：200%倍率 + 8秒CD → 偏强，建议降至180% 或 CD 延长至10秒
- **升级效果**：Lv3 眩晕1秒 → 控制过强，建议改为“减速提升至70%”或“附加易伤”
- **被动**：击杀叠层（最高30%）→ 在清小怪时过强，建议每层持续独立刷新而非叠加时长

##### 张飞 - 当阳怒吼
- **机制**：范围眩晕 + 斩杀 + 减伤 → 设计优秀，符合坦克定位
- **数值**：150%倍率，对低血翻倍 → 可能抢输出位，建议斩杀倍率降至1.5倍（总225%）
- **被动**：半血狂暴、残血不屈 → 很好，但30%减伤过高，建议改为20%
- **羁绊**：与关羽同时上阵时生命回复+50% → 若队伍有治疗辅助，可能导致张飞过肉，建议改为“受到治疗量+30%”

##### 赵云 - 七进七出
- **机制**：多段穿人 + 回血 + CD刷新 → 非常有趣，但实现复杂（需处理碰撞、位移、目标计数）
- **数值**：每次穿过100%伤害 → 若敌人密集，总伤害爆炸。建议每次伤害递减（首次100%，之后80%）
- **被动**：自动触发一次“龙魂”冲刺（60秒CD）→ 保命能力过强，建议改为“生命低于30%时，获得50%闪避3秒”
- **性能风险**：6秒CD + 穿人 + 回血 + 重置，需大量逻辑判断，建议增加技能释放后0.5秒不可再次释放的“冷却保护”

##### 马超 - 神威天降
- **机制**：跃击 + 范围高伤 + 击杀重置 → 类似传统刺客大招
- **数值**：350%/400%倍率，对BOSS额外+100% → 总伤害可达800%，一击秒杀精英，严重超模。建议：
  - 基础倍率降至250%，中心额外30%
  - 对BOSS额外伤害改为“造成目标已损失生命值15%的额外伤害”
- **被动**：暴击率+20%，暴伤+50% → 配合装备可能达到100%暴击，建议暴击率上限设为60%，暴伤上限200%
- **羁绊**：与黄忠同时上阵，双方暴伤+30% → 与马超被动叠加后暴伤可达80%+，建议改为“暴击时回复5%生命”

##### 黄忠 - 烈弓连珠
- **机制**：锁定最高生命目标 + 多箭连射 + 防御削减 → 适合BOSS战
- **数值**：5箭×180% = 900%倍率，对低血额外+50% → 单技能可秒杀任何非BOSS，建议：
  - 每箭倍率降至120%，总倍率600%
  - 对低血加成改为“每箭额外造成目标2%最大生命值的伤害（上限200）”
- **被动**：生命每降低10%，攻速+5%（最高+40%）→ 与“远程安全输出”矛盾，低血时反而鼓励站桩，建议改为“每保持原地攻击1秒，攻速+5%（最高20%），移动后重置”

#### 3. 羁绊系统

| 羁绊 | 评审意见 |
|------|----------|
| 五虎上将 | 全属性+20% 过强，建议改为“攻击+15%，生命+10%”。联合技500%平均攻击力 → 需明确平均攻击力计算方式（是否包含加成），建议改为“对全屏敌人造成300%攻击力的真实伤害”。30%免死 → 在 Roguelike 中过于珍贵，建议改为“每场战斗首次受到致命伤害时，保留1点生命并获得2秒无敌” |
| 桃园结义 | 生命回复+50% → 与张飞羁绊重复，建议改为“双方控制时间减少30%” |
| 西凉双雄 | 对BOSS伤害+25% → 与黄忠被动叠加达55%，建议改为“双方普攻有20%几率附加流血” |
| 蜀汉先锋 | 技能CD-15% → 赵云6秒变5.1秒，马超12秒变10.2秒，可能导致技能循环过密，建议改为“技能冷却期间，移动速度+15%” |
| 五虎前军 | 暴击附加5%最大生命伤害 → 对BOSS单次暴击附加数千伤害，建议改为“暴击时额外造成目标当前生命值3%的伤害（上限500）” |

---

#### 4. 与 Roguelike 核心循环的融合度

当前文档偏向 **传统RPG** 设计，与之前确定的“2D俯视角动作Roguelike”需要强化以下整合点：

| 传统RPG机制 | 需改造为 Roguelike 机制 |
|-------------|------------------------|
| 等级成长（1-60级） | 改为局内升级（每关选择属性提升） |
| 技能升级（消耗技能点） | 改为祝福/神恩三选一（类似Hades） |
| 天赋树 | 改为随机出现的被动能力，每局重置 |
| 固定羁绊 | 改为每局中通过特定事件/道具激活临时羁绊 |
| 装备系统 | 改为武器变异（6种基础武器 × 属性附魔） |

**建议**：
- 保留五虎将的基础技能和数值，但移除“等级”和“技能点”，改为**局内成长**
- 将“羁绊”改为**局内组合**：每获得一个五虎将，激活一层羁绊效果（类似自走棋）
- 引入 **“血怒”系统**（之前策划案）：五虎将共享血怒槽，满槽可触发联合技

---

#### 5. 美术与AI生成

- 提供的像素艺术提示词质量较高，但部分细节（如“Game Boy Advance style”）可能与 Holopix 风格不完全匹配。建议统一为 `holopix art style, top-down pixel art, 16-bit, transparent background`
- 技能特效提示词需要更明确的**帧数**和**尺寸**要求，建议追加 `8 frames loop, 128x128, sprite sheet`
- 角色尺寸48x48在俯视角游戏中可能偏小（细节看不清），建议改为 **64x64** 或 **96x96**

---

#### 6. 技术实现风险

| 模块 | 风险 | 缓解措施 |
|------|------|----------|
| 赵云七进七出 | 多段位移 + 碰撞检测 + 回血逻辑 | 使用 Area2D 作为攻击判定，每段位移触发一次；限制最大穿过次数（如10次） |
| 黄忠烈弓连珠 | 锁定目标 + 连续5箭 + 自动切换 | 每箭间隔0.4秒，期间目标死亡需重新搜索，建议简化：只锁定释放瞬间的目标，若死亡则剩余箭矢打空 |
| 马超神威天降 | 跃起 + 砸地 + 范围判定 | 需要处理空中状态（无敌/不可选中），建议使用 AnimationPlayer + 临时改变碰撞层 |
| 羁绊动态激活 | 5人同时上阵时的联合技触发 | 需要监听所有武将的技能释放信号，使用信号总线统一协调 |
| 数值平衡 | 技能倍率过高，可能导致秒杀 | 建立伤害公式测试框架，使用自动化测试验证每个技能在不同装备/等级下的伤害范围 |

### 三、改进建议汇总

#### 高优先级（必须修改）
1. **降低马超和黄忠的技能倍率**，避免秒杀BOSS
2. **明确与 Roguelike 的融合方案**，移除等级成长，改为局内随机成长
3. **简化赵云和赵云的技能实现复杂度**，增加冷却保护
4. **调整五虎羁绊数值**，从20%全属性降至15%攻击+10%生命

#### 中优先级（建议修改）
5. 重新平衡基础属性，拉大坦克与脆皮的差距
6. 修改部分羁绊效果（桃园结义、西凉双雄）避免过度叠加
7. 增加“血怒系统”与五虎将的联动（如每个武将击杀敌人贡献血怒值）
8. 补充 **Godot 4 实现伪代码** 或 **关键节点结构**，便于开发落地

#### 低优先级（可选优化）
9. 为每个武将设计专属的“觉醒”效果，作为局内终极祝福
10. 增加武将之间的对话互动（提升沉浸感）
11. 完善验收标准中的性能测试用例（如同屏10个敌人+五虎将同时放技能）

---

### 四、结论

**当前方案可作为 MVP 阶段的详细设计蓝本**，但必须进行上述高优先级调整后方可进入开发。建议在开发前：

1. 使用 Excel 或 Google Sheets 建立完整的数值模拟模型，测试不同等级/装备下的伤害输出
2. 在 Godot 中快速搭建原型场景，只实现关羽和张飞的普攻+1个技能，验证手感
3. 与 AI 美术生成流程对接，生成一版五虎将的64x64精灵表，确认风格统一

**总体评分**：7.5/10（设计完整但数值和Roguelike融合需加强）
