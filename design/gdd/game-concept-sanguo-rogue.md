# 游戏概念：三国像素幸存者

> **工作标题**：三国像素幸存者\
> **类型**：Roguelite / 幸存者 / 动作\
> **风格**：16-bit 像素风\
> **平台**：移动端（iOS/Android）\
> **开发周期**：1-2 个月 MVP

***

## 电梯演讲

> 这是一款**吸血鬼幸存者式**的移动端肉鸽游戏，你在**16-bit像素风**的三国战场上扮演名将，通过**走位闪避**和**自动攻击**来对抗千军万马。每局游戏你可以**开局选择武将**，并在战斗中**招募其他武将**组成军团，体验"一夫当关，万夫莫开"的爽快感。

***

## 核心幻想

**"成为三国名将，在千军万马中杀出一条血路！"**

玩家幻想：

- 扮演喜爱的三国武将（关羽、赵云、吕布等）
- 体验"万军丛中取上将首级"的爽快感
- 组建自己的梦幻军团
- 通过策略Build打造无敌组合
- 在经典三国战役中生存下来

***

## 独特卖点

**"吸血鬼幸存者 + 三国武将收集 + 军团组建"**

- ✅ **熟悉的核心循环**：吸血鬼幸存者已被验证的爽快感
- ✅ **情感连接**：三国武将的收集和培养
- ✅ **策略深度**：武将组合和技能搭配
- ✅ **文化共鸣**：经典三国题材

## 玩家体验分析（MDA 框架）

### 目标美学（玩家感受到什么）

| 美学     | 优先级   | 我们如何交付          |
| ------ | ----- | --------------- |
| **挑战** | ⭐⭐⭐⭐⭐ | 生存压力、Boss战、难度递增 |
| **幻想** | ⭐⭐⭐⭐⭐ | 扮演三国名将、经典武器     |
| **表达** | ⭐⭐⭐⭐  | 武将Build、技能组合    |
| **发现** | ⭐⭐⭐⭐  | 新武将解锁、技能组合探索    |
| **感官** | ⭐⭐⭐   | 16-bit像素风、粒子特效  |
| **叙事** | ⭐⭐    | 战役背景、武将故事       |
| **友谊** | ⭐     | 单机游戏，但武将之间有羁绊   |
| **沉浸** | ⭐     | 短时游戏，不追求沉浸      |

### 关键动态（涌现的玩家行为）

1. **武将Build探索**：玩家尝试不同武将的技能组合
2. **军团策略**：根据武将羁绊和技能搭配组建最优军团
3. **走位艺术**：在敌群中穿梭，寻找最佳站位
4. **资源管理**：经验、金币、血量的权衡

### 核心机制（我们构建的系统）

1. **自动攻击系统**：武将自动攻击范围内的敌人
2. **武将招募系统**：战斗中招募其他武将加入军团
3. **升级选择系统**：三选一升级，Build武将能力
4. **羁绊系统**：特定武将组合触发强力羁绊效果
5. **战役关卡系统**：长坂坡、赤壁等经典战役场景

## 玩家动机画像

### 主要心理需求满足

| 需求      | 这款游戏如何满足它         | 强度 |
| ------- | ----------------- | -- |
| **自主性** | 武将选择、Build自由、策略多样 | 核心 |
| **能力**  | 技能成长、生存时间、通关成就    | 核心 |
| **关联性** | 三国文化认同、武将情感连接     | 支持 |

### 玩家类型吸引力（Bartle 分类法）

- ✅ **成就者**：武将收集、通关成就、排行榜
- ✅ **探索者**：技能组合探索、Build优化
- ⭐ **社交者**：单机游戏，较少社交元素
- ✅ **竞争者**：生存时间挑战、排行榜竞争

### 心流状态设计

- **入门曲线**：前 3 分钟教会基本操作（移动、攻击、升级）
- **难度缩放**：每 2 分钟一波强力敌人，5 分钟 Boss
- **反馈清晰度**：伤害数字、经验条、升级提示
- **从失败中恢复**：快速重开，保留部分进度

***

## 核心循环

### 即时（30 秒）

移动 → 攻击 → 收集经验/金币 → 躲避敌人

### 短期（5-10 分钟）

生存 → 升级 → 选择技能 → 招募武将 → 应对更强敌人

### 会话级别（15-20 分钟）

选择武将 → 进入战役 → 生存尽可能久 → Boss战 → 结算奖励

### 长期进度

- 解锁新武将
- 升级武将等级
- 解锁新技能
- 解锁新战役
- 收集皮肤/称号

### 留存钩子

- **好奇心**：下一个武将会是谁？
- **投入**：武将培养进度
- **精通**：生存时间挑战、排行榜

## 游戏支柱

### 支柱 1：爽快的幸存者体验

**定义**：核心循环必须是即时满足的，每局都有成长感。

*设计测试*：如果我们在"更复杂的系统"和"更爽快的体验"之间争论，这个支柱选择后者。

### 支柱 2：武将收集与羁绊

**定义**：武将是核心，收集和组合武将是主要乐趣来源。

*设计测试*：如果我们在"更多敌人种类"和"更多武将"之间争论，这个支柱选择后者。

### 支柱 3：策略Build深度

**定义**：简单的操作，深度的策略选择。

*设计测试*：如果我们在"自动攻击"和"手动攻击"之间争论，这个支柱选择自动攻击（简单操作），但要求技能选择有深度。

### 反支柱（这款游戏不是什么）

- **不是硬核动作**：不需要精确操作，走位即可
- **不是复杂策略**：不需要暂停思考，即时决策
- **不是长叙事**：没有长篇剧情，背景设定即可
- **不是付费获胜**：武将可以通过游戏解锁

## 风险和未决问题

### 设计风险

- 武将平衡性难以把握
- 20+武将的技能设计工作量巨大
- 移动端操作适配

### 技术风险

- 同屏大量敌人的性能优化
- 低端手机兼容性

### 市场风险

- 幸存者类游戏竞争激烈
- 三国题材同质化

### 未决问题

- 武将获取方式（抽卡？解锁？）
- 货币化策略的具体设计
- 社交/排行榜功能范围

***

## MVP 定义

**核心假设**：玩家喜欢"吸血鬼幸存者 + 三国武将"的组合

**MVP 必需**：

1. 3-5 个核心武将（关羽、赵云、吕布、诸葛亮、貂蝉）
2. 1 个战役关卡（长坂坡）
3. 基础升级系统（10 个技能）
4. 武将招募系统（2 人军团）
5. 基础UI和音效

**明确不在 MVP 中**：

- 20+武将（MVP后逐步添加）
- 多战役（MVP后添加）
- 复杂的羁绊系统
- 皮肤/装饰系统
- 排行榜
